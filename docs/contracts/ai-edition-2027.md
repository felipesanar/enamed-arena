# IA e MCP no contexto da edição

DTO aditivo `AiEditionContext` em src/types/ai-edition.ts. Cliente futuro envia edição real da prova/série, formato validado, TopX% de computePercentile e referência de corte com fonte conhecida ou null. Servidor valida contexto contra catálogo autorizado; dados de outra edição não entram em uma mesma série. Nenhuma análise calcula score, altera dados ou inventa proficiência TRI. Sem contexto legado, texto assume formato/corte desconhecidos; não usar100questões/4horas/GOAL50 como substituto.

Primeira entrega servidor: gemini-performance-summary, gemini-ranking-summary e gemini-comparative-summary aceitam o contexto aditivo mantendo payload legado. Autenticação de usuário real, não mera presença de header; dados de catálogo/corte via cliente JWT do caller. Se contexto explícito é inválido ou contradiz o simulado identificado, recusar400. Contexto indisponível fica desconhecido, sem inventar fonte. Percentil é o mesmo valor numérico do cliente, validado1..99/null, nunca100-nota ou cálculo alternativo da IA. Fonte de corte desconhecida impede alegar chance de aprovação; ressalva de escalas diferentes/TRI permanece no prompt.

Modelo das três funções passa a `GEMINI_MODEL`, com fallback no modelo já utilizado, validado/escapado na URL. Testes não chamam Gemini/Supabase reais nem usam keys. A configuração de outros endpoints Gemini e payloads de caderno será integrada na etapa de caderno, sem declarar esta entrega completa para todos os endpoints.

MCP get_my_performance abandona SELECT user_performance_summary e chama get_user_performance_summary com usuário do OAuth, edição explícita/resolvida e include_training=false. Input opcional edition_id UUID. Sem input: alvo explícito, graduação correspondente, catálogo corrente; sem resolução, resultado neutro sem média global. Retorno inclui scope e só resultados liberados pelo RPC. Não ler notas brutas para contornar gate. Source TypeScript/auth/RLS/PRO continuam verificados; bundle só por gerador oficial Linux e pins, sem editar artefato à mão.
